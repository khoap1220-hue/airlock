Issue #23 asked to enable Dependabot for Actions and pip, and settle how its pull requests
pass the roadmap gate without weakening Decision D-07 ("Roadmap gate has no exemptions,
including dependency bumps").

PR #115 established the baseline `.github/dependabot.yml` for both ecosystems and PR #118
demonstrated that Dependabot PRs need a `docs/changes/` record before merging.

This change settles the mechanical workflow:
1. Adds `scripts/record_dependabot_bump.py` (Python 3.11 standard library only). The helper
   analyzes the git diff against the base branch, parses updated `dev` dependencies in
   `pyproject.toml` (or pinned action SHAs in `.github/workflows/`), writes a valid
   `docs/changes/` record, recompiles `requirements-ci.txt` with `uv pip compile` if dev
   dependencies changed, and regenerates `ROADMAP.md` via `scripts/roadmap_progress.py`.
2. Adds unit test coverage in `tests/unit/test_roadmap_gate.py` verifying that records
   generated by `record_dependabot_bump.py` satisfy `scripts/check_roadmap_touched.sh` and pass
   `python scripts/roadmap_progress.py --check`.
3. Documents the Dependabot merge procedure in `CONTRIBUTING.md` and `AGENTS.md`, reaffirming
   that pinned Action diffs and review tags must be verified prior to merge.
4. Updates `ROADMAP.md` Decision D-07 and task 1.6 to record the mechanical settlement.
